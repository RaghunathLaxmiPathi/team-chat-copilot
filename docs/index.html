Team Chat with Copilot

A team chat service for about ten people, designed from assumptions outward and documented at every step. It includes direct messages, group chats, channels, threads, real-time delivery, and an AI assistant that runs on a model on your own computer.

Read the requirements See the architecture View the code

What it does

Real-time team chat

Direct messages, group chats, channels, threads, mentions, markdown, attachments, search, and notifications. Messages arrive instantly and in order, with nothing missed or duplicated after a dropped connection.

Copilot, a real AI assistant

Joins every group and channel, replies to everything you write when you let it, and answers from a language model running on your own computer. Your history and details are used only in your private chat.

Live data

The time in any place, live weather, who has the chat open, and live service health for administrators.

Measured objectives

Success Rate and delivery latency at P50, P75, P90, P95, and P99 over 1 hour, 24 hours, and 28 days, with minimum sample rules and a burn-rate warning.

Privacy by design

Server-side membership checks everywhere, deletion that reaches every copy, logs with no message text or tokens, and a data boundary around what the AI is given.

Tested

105 automated tests cover ordering, retries, permissions, deletion, real-time delivery, the objectives, privacy, and the assistant.

Try it

The chat needs its server, so it cannot run on this page. It runs on your own computer with two commands and needs no database server, message broker, or container:

cd chatapp
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m app

Then open http://127.0.0.1:8000/ and sign in as alice, bob, carol, admin1, or admin2. For the AI assistant, install Ollama and run ollama pull llama3.2:3b once.
